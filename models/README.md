# models/

Generated by `scripts/train_model.py`. Contains:

- `disease_model.joblib` — trained `RandomForestClassifier`
- `label_encoder.joblib` — maps model output indices to disease names
- `symptoms_list.json` — ordered list of the 134 symptom features the model expects
- `model_metrics.json` — accuracy + train/test split sizes from the last training run

## Upgrading to a real image-detection CNN

The image detection module (`backend/app/services/image_service.py`) is
currently a placeholder heuristic. To make it real:

1. Collect/license a labeled image dataset for your target condition(s)
   (e.g. a dermatology dataset for skin conditions).
2. Train a CNN via transfer learning (e.g. `MobileNetV2` / `EfficientNet`
   base + a custom classification head) with TensorFlow/Keras or PyTorch.
3. Save the trained model to `models/image_model/` (e.g. `.keras` or `.pt`).
4. In `image_service.py`, replace `classify_image()` with code that loads
   this model once at import time and runs `model.predict()` on the
   preprocessed upload, keeping the same return shape:
   `{"predicted_class": str, "confidence": float, "recommendation": str}`.
